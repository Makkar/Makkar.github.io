Kernels - Part 2

Introduction

We discussed some functional analysis and the basics of Reproducing Kernel Hilbert Space theory in a previous two blog posts. The aim of this article is to discuss the need for approximating the kernel matrix and one method in particular to do that, Random Fourier Features.

Let's start by discussing Kernel Ridge Regression, a simple application of kernel methods.

Kernel Ridge Regression

Ridge Regression

Let's recall the ridge regression model. We have some training data of the form:

(x1,y1),…,(xn,yn)∈(𝒳,𝒴),\begin{aligned} (x_1, y_1), \ldots, (x_n, y_n) \in (\mathcal{X}, \mathcal{Y}),\end{aligned}

where 𝒳=ℝd\mathcal{X} = \mathbb R^d and 𝒴=ℝ.\mathcal{Y} = \mathbb R. We represent the training data more succinctly by letting 𝐲=[y1,…,yn]⊤\mathbf{y} = [y_1, \ldots, y_n]^\top and 𝐗\mathbf{X} be an n×dn \times d matrix whose ithi^{\text{th}} row is xi⊤.x_i^\top. Then in ridge regression the likelihood model is

𝐲∼𝒩(𝐗𝐰,σ2𝐈n),\begin{aligned} \mathbf{y} \sim \mathcal{N}(\mathbf{X} \mathbf{w}, \sigma^2 \mathbf{I}_n),\end{aligned}

where 𝐰\mathbf{w} is a dd-dimensional column vector representing the weights to learned, and σ2>0.\sigma^2 > 0. We also assume a Gaussian prior on 𝐰\mathbf{w}

𝐰∼𝒩(0,1λ𝐈d).\begin{aligned} \mathbf{w} \sim \mathcal{N}\left(0, \frac{1}{\lambda} \mathbf{I}_d\right).\end{aligned}

Then the maximum a posteriori (MAP) estimate is given by

𝐰MAP=arg max𝐰⁡ln⁡p(𝐰|𝐲,𝐗)=arg max𝐰⁡ln⁡p(𝐲|𝐰,𝐗)+ln⁡p(𝐰)=arg max𝐰⁡−12σ2(𝐲−𝐗𝐰)⊤(𝐲−𝐗𝐰)−λ2𝐰⊤𝐰⏟ℒ\begin{aligned} \begin{align*}\mathbf{w}_{\text{MAP}} &= \argmax _{\mathbf{w}} \; \ln p(\mathbf{w} | \mathbf{y}, \mathbf{X}) \\ &= \argmax _{\mathbf{w}} \; \ln p(\mathbf{y} | \mathbf{w}, \mathbf{X}) + \ln p(\mathbf{w}) \\ &= \argmax _{\mathbf{w}} \; \underbrace{-\frac{1}{2\sigma^2} (\mathbf{y} - \mathbf{X} \mathbf{w})^\top (\mathbf{y} - \mathbf{X} \mathbf{w}) - \frac{\lambda}{2} \mathbf{w}^\top \mathbf{w}} _{\mathcal{L}}\end{align*}\end{aligned}

If we call this objective ℒ\mathcal{L}, then 𝐰MAP\mathbf{w}_{\text{MAP}} is given by the solution of the equation formed by equating the gradient of ℒ\mathcal{L} with respect to 𝐰\mathbf{w} to 0.0. Thus,

0=∇𝐰ℒ=1σ2𝐗⊤𝐲−1σ2𝐗⊤𝐗𝐰−λ𝐰\begin{aligned} 0 = \nabla_{\mathbf{w}} \mathcal{L} = \frac{1}{\sigma^2} \mathbf{X}^\top \mathbf{y} - \frac{1}{\sigma^2} \mathbf{X}^\top \mathbf{X} \mathbf{w} - \lambda \mathbf{w}\end{aligned}

and we get

𝐰MAP=(λσ2𝐈+𝐗⊤𝐗)−1𝐗⊤𝐲,\begin{aligned} \mathbf{w}_{\text{MAP}} = (\lambda \sigma^2 \mathbf{I} + \mathbf{X}^\top \mathbf{X})^{-1} \mathbf{X}^\top \mathbf{y},\end{aligned}

which is called the ridge regression solution, and we denote it by 𝐰RR.\mathbf{w}_{\text{RR}}. We are inverting a d×dd \times d matrix taking 𝒪(d3)\mathcal{O}(d^3) time, and matrix multiplication of a d×dd \times d matrix with a d×nd \times n matrix taking 𝒪(d2n)\mathcal{O}(d^2 n) time.

Kernel Ridge Regression

The previous model suffers from limited expressiveness. As we have seen before, the idea of kernel methods is to define a map which takes our inputs from 𝒳\mathcal{X} to an RKHS ℋ\mathcal{H},

ϕ:𝒳→ℋ\begin{aligned} \phi \colon \mathcal{X} \to \mathcal{H}\end{aligned}

and then apply the linear model of ridge regression above to ϕ(xi)\phi(x_i) instead of xi.x_i. ℋ\mathcal{H} could be an infinite-dimensional vector space, but for now suppose it is DD-dimensional. Let 𝚽\mathbf{\Phi} represent the n×Dn \times D matrix whose ithi^{\text{th}} row is ϕ(xi)⊤.\phi(x_i)^\top. Then the ridge regression solution is given by

𝐰RR=(λσ2𝐈D+𝚽⊤𝚽)−1𝚽⊤𝐲.\begin{aligned} \mathbf{w}_{\text{RR}} = (\lambda \sigma^2 \mathbf{I}_D + \mathbf{\Phi}^\top \mathbf{\Phi})^{-1} \mathbf{\Phi}^\top \mathbf{y}.\end{aligned}

We immediately realize the problem here: we are inverting a D×DD \times D matrix and DD can be huge! Fortunately, we have a matrix trick that we can exploit, the push-though identity. It looks like this

𝚽⊤(λσ2𝐈n+𝚽𝚽⊤)=(λσ2𝐈D+𝚽⊤𝚽)𝚽⊤(λσ2𝐈D+𝚽⊤𝚽)−1𝚽⊤(λσ2𝐈n+𝚽𝚽⊤)=(λσ2𝐈D+𝚽⊤𝚽)−1(λσ2𝐈D+𝚽⊤𝚽)𝚽⊤(λσ2𝐈D+𝚽⊤𝚽)−1𝚽⊤(λσ2𝐈n+𝚽𝚽⊤)=𝚽⊤(λσ2𝐈D+𝚽⊤𝚽)−1𝚽⊤(λσ2𝐈n+𝚽𝚽⊤)(λσ2𝐈n+𝚽𝚽⊤)−1=𝚽⊤(λσ2𝐈n+𝚽𝚽⊤)−1(λσ2𝐈D+𝚽⊤𝚽)−1𝚽⊤=𝚽⊤(λσ2𝐈n+𝚽𝚽⊤)−1.\begin{aligned} \mathbf{\Phi}^\top (\lambda \sigma^2 \mathbf{I}_n + \mathbf{\Phi} \mathbf{\Phi}^\top) &= (\lambda \sigma^2 \mathbf{I}_D + \mathbf{\Phi}^\top \mathbf{\Phi}) \mathbf{\Phi}^\top \\ (\lambda \sigma^2 \mathbf{I}_D + \mathbf{\Phi}^\top \mathbf{\Phi})^{-1} \mathbf{\Phi}^\top (\lambda \sigma^2 \mathbf{I}_n + \mathbf{\Phi} \mathbf{\Phi}^\top) &= (\lambda \sigma^2 \mathbf{I}_D + \mathbf{\Phi}^\top \mathbf{\Phi})^{-1} (\lambda \sigma^2 \mathbf{I}_D + \mathbf{\Phi}^\top \mathbf{\Phi}) \mathbf{\Phi}^\top \\ (\lambda \sigma^2 \mathbf{I}_D + \mathbf{\Phi}^\top \mathbf{\Phi})^{-1} \mathbf{\Phi}^\top (\lambda \sigma^2 \mathbf{I}_n + \mathbf{\Phi} \mathbf{\Phi}^\top) &= \mathbf{\Phi}^\top \\ (\lambda \sigma^2 \mathbf{I}_D + \mathbf{\Phi}^\top \mathbf{\Phi})^{-1} \mathbf{\Phi}^\top (\lambda \sigma^2 \mathbf{I}_n + \mathbf{\Phi} \mathbf{\Phi}^\top) (\lambda \sigma^2 \mathbf{I}_n + \mathbf{\Phi} \mathbf{\Phi}^\top)^{-1} &= \mathbf{\Phi}^\top (\lambda \sigma^2 \mathbf{I}_n + \mathbf{\Phi} \mathbf{\Phi}^\top)^{-1} \\ (\lambda \sigma^2 \mathbf{I}_D + \mathbf{\Phi}^\top \mathbf{\Phi})^{-1} \mathbf{\Phi}^\top &= \mathbf{\Phi}^\top (\lambda \sigma^2 \mathbf{I}_n + \mathbf{\Phi} \mathbf{\Phi}^\top)^{-1}. \end{aligned}

And thus we get

𝐰RR=𝚽⊤(λσ2𝐈n+𝚽𝚽⊤)−1𝐲.\begin{aligned} \mathbf{w}_{\text{RR}} = \mathbf{\Phi}^\top (\lambda \sigma^2 \mathbf{I}_n + \mathbf{\Phi} \mathbf{\Phi}^\top)^{-1} \mathbf{y}.\end{aligned}

We are now inverting an n×nn \times n matrix taking 𝒪(n3)\mathcal{O}(n^3) time, and matrix multiplication of a D×nD \times n matrix with a n×nn \times n matrix taking 𝒪(Dn2)\mathcal{O}(D n^2) time.

Notice that 𝚽𝚽⊤\mathbf{\Phi} \mathbf{\Phi}^\top is the gram matrix, and let's denote it by 𝐊.\mathbf{K}. Its (i,j)th(i,j)^{\text{th}} entry is 𝐊i,j=⟨ϕ(xi),ϕ(xj)⟩=K(xi,xj)\mathbf{K}_{i,j} = \left\langle \phi(x_i),\phi(x_j) \right\rangle = K(x_i, x_j), where K:ℝd×ℝd→ℂK \colon \mathbb R^d \times \mathbb R^d \to \mathbb{C} is the kernel function corresponding to the RKHS ℋ.\mathcal{H}.

If we denote

𝛂=(λσ2𝐈n+𝚽𝚽⊤)−1𝐲=(λσ2𝐈n+𝐊)−1𝐲\begin{aligned} \mathbf{\alpha} = (\lambda \sigma^2 \mathbf{I}_n + \mathbf{\Phi} \mathbf{\Phi}^\top)^{-1} \mathbf{y} = (\lambda \sigma^2 \mathbf{I}_n + \mathbf{K})^{-1} \mathbf{y}\end{aligned}
then we have
𝐰RR=𝚽⊤𝛂=∑i=1nαiϕ(xi),\begin{aligned} \mathbf{w}_{\text{RR}} = \mathbf{\Phi}^\top \mathbf{\alpha} = \sum _{i=1}^n \alpha_i \phi(x_i),\end{aligned}
and prediction for a test data point, xx, is
𝐰RR⊤ϕ(x)=∑i=1nαiϕ(xi)⊤ϕ(x)=∑i=1nαikxi(x),\begin{aligned} \mathbf{w}_{\text{RR}}^\top \phi(x) = \sum _{i=1}^n \alpha_i \phi(x_i)^\top \phi(x) = \sum _{i=1}^n \alpha_i k _{x_i}(x),\end{aligned}
where kxik_{x_i} denotes the reproducing kernel for the point xi.x_i.

If this looks suspiciously similar to the Representer theorem (Theorem-8 here), then that's because it is an instance of it! So prediction takes 𝒪(n)\mathcal{O}(n) time.

The point of this discussion was to show that Kernel Ridge Regression is computationally expensive. Simply storing the gram matrix, 𝐊\mathbf{K}, takes 𝒪(n2)\mathcal{O}(n^2) space. We need to find methods which can circumvent using 𝐊\mathbf{K} if we are to apply kernel methods to anything other than the smallest of the data sets.

Kernel Approximation

The idea behind kernel approximation methods is to replace the gram matrix, 𝐊\mathbf{K}, with a low rank approximation, i.e., find an n×Sn \times S matrix, 𝐙\mathbf{Z}, such that

𝐊≈𝐙𝐙⊤.\begin{aligned} \mathbf{K} \approx \mathbf{Z} \mathbf{Z}^\top.\end{aligned}

We want S≪nS \ll n, and thus we significantly reduce our time and space complexity. 𝐙\mathbf{Z} takes only 𝒪(nS)\mathcal{O}(nS) space. Inversion of (λσ2𝐈n+𝐙𝐙⊤)(\lambda \sigma^2 \mathbf{I}_n + \mathbf{Z} \mathbf{Z}^\top) takes only 𝒪(nS2)\mathcal{O}(n S^2) time.

One way to think about this is we want to find a mapping of xix_i's to some latent space such that the inner product in this latent space approximates the kernel

𝐊i,j=K(xi,xj)≈zi⊤zj,\begin{aligned} \mathbf{K}_{i,j} = K(x_i, x_j) \approx z_i^\top z_j,\end{aligned}
where ziz_i denotes the ithi^\text{th} row of 𝐙.\mathbf{Z}. One popular way to do that is by Nyström approximation, which I won't be discussing at all. The other popular method is to use random Fourier features. This approach was introduced by Rahimi and Recht in their seminal 2007 paper Random Features for Large-Scale Kernel Machines. It relies on a result from functional analysis called Bochner's theorem, so let's digress and discuss that first.

Bochner’s Theorem

Definition 28: A function K:ℝn→ℂK : \mathbb R^n \to \mathbb{C}, is said to be positive-definite if
∑i,j=1nαiαjK(xi−xj)≥0\begin{aligned} \sum _{i,j = 1}^n \alpha_i \overline{\alpha}_j K(x_i - x_j) \geq 0\end{aligned}
for every choice of x1,…,xn∈ℝnx_1, \ldots, x_n \in \mathbb R^n and for every choice of complex numbers α1,…,αn.\alpha_1, \ldots, \alpha_n.

Notice how similar this definition is to the definition of a kernel function. Positive-definite functions have some nice properties:

Lemma 3: If K:ℝn→ℂK: \mathbb R^n \to \mathbb{C} is a positive-definite function, then K(−x)=K(x)K(-x) = \overline{K(x)} for every x∈ℝn.x \in \mathbb R^n.
It is easy to see that K(0)≥0.K(0) \geq 0. In the definition 28 above, let n=2n = 2, x1=xx_1 = x, x2=0x_2 = 0, α1\alpha_1 be an arbitrary complex number, and α2=1.\alpha_2 = 1. Then applying the definition of a positive-definite function, we get
(1+|α1|2)K(0)+α1K(x)+α1K(−x)≥0.\begin{aligned} (1 + |\alpha_1|^2)K(0) + \alpha_1 K(x) + \overline{\alpha}_1K(-x) \geq 0.\end{aligned}
Let α1=1\alpha_1 = 1, then
2K(0)+K(x)+K(−x)≥0.\begin{aligned} 2K(0) + K(x) + K(-x) \geq 0.\end{aligned}
In particular, K(x)+K(−x)K(x) + K(-x) is real, which implies
K(x)+K(−x)=K(x)+K(−x).\begin{aligned} K(x) + K(-x) = \overline{K(x)} +\overline{K(-x)}.\end{aligned}
Similarly, letting α1=i\alpha_1 = i, we get i(K(x)−K(−x))i(K(x) - K(-x)) is real, which implies
K(x)−K(−x)=−K(x)+K(−x).\begin{aligned} K(x) - K(-x) = -\overline{K(x)} + \overline{K(-x)}.\end{aligned}
Adding these two equations, we get K(−x)=K(x).K(-x) = \overline{K(x)}.
Lemma 4: If K:ℝn→ℂK: \mathbb R^n \to \mathbb{C} is a positive-definite function, then KK is bounded. In particular, |K(x)|≤K(0)|K(x)| \leq K(0) for every x∈ℝn.x \in \mathbb R^n.
From lemma-3, K(0)K(0) must be real. In the definition above, let n=2n = 2, x1=0x_1 = 0, x2=xx_2 = x, α1=|K(x)|\alpha_1 = |K(x)|, and α2=−K(x).\alpha_2 = -\overline{K(x)}. Then applying the definition of a positive-definite function, we get
2K(0)|K(x)|2−|K(x)|K(x)K(−x)−K(x)|K(x)|K(x)≥0.\begin{aligned} 2K(0) \left|K(x)\right|^2 - |K(x)| K(x) K(-x) - \overline{K(x)} |K(x)| K(x) \geq 0.\end{aligned}
Now use lemma-3 to substitute K(x)\overline{K(x)} for K(−x)K(-x) in the middle term to get
2K(0)|K(x)|2−2|K(x)|3≥0.\begin{aligned} 2K(0) |K(x)|^2 - 2 |K(x)|^3 \geq 0.\end{aligned}
If |K(x)|=0|K(x)| = 0, then we obviously have our result, since we can easily show K(0)≥0K(0) \geq 0, otherwise we can divide by 2|K(x)|22|K(x)|^2 to get
K(0)−|K(x)|≥0,\begin{aligned} K(0) - |K(x)| \geq 0,\end{aligned}
which is our desired result.

The following theorem is the converse of Bochner's theorem. We state it first since it is easier to prove.

Theorem 9 [Converse of Bochner's theorem]: The Fourier transform of every finite Borel measure on ℝn\mathbb R^n is positive-definite.
Let μ\mu be a finite Borel measure on ℝn.\mathbb R^n. Let K:ℝn→ℂK : \mathbb R^n \to \mathbb{C} be the Fourier transform of μ\mu, i.e.,
K(x)=∫ℝnexp⁡(−iω⊤x)dμ(ω).\begin{aligned} K(x) = \int_{\mathbb R^n} \exp(-i \omega^\top x) \,\mathrm{d}\mu(\omega).\end{aligned}
Let x1,…,xn∈ℝnx_1, \ldots, x_n \in \mathbb R^n and α1,…,αn∈ℂ\alpha_1, \ldots, \alpha_n \in \mathbb{C} be arbitrary. Then
∑i,j=1nαiαjK(xi−xj)=∑i,j=1nαiαj∫ℝnexp⁡{−iω⊤(xi−xj)}dμ(ω)=∫ℝn|∑i=1nαiexp⁡(−iω⊤xi)|2dμ(ω)≥0.\begin{aligned} \sum _{i,j = 1}^n \alpha_i \overline{\alpha}_j K(x_i - x_j) &= \sum _{i,j = 1}^n \alpha_i \overline{\alpha}_j \int _{\mathbb R^n} \exp\{-i \omega^\top (x_i - x_j)\} \,\mathrm{d}\mu(\omega) \\ &= \int_{\mathbb R^n} \left| \sum_{i = 1}^n \alpha_i \exp(-i \omega^\top x_i) \right|^2 \mathrm{d}\mu(\omega) \\&\geq 0. \end{aligned}
Thus, KK is positive-definite.
Theorem 10 [Bochner's theorem]: If KK is continuous and positive-definite, then KK is the Fourier transform of a finite positive Borel measure.

I'll skip the proof since it is beyond my understanding. The proof can be easily found on the internet, see here or here for example.

This finite positive Borel measure is often called as spectral measure. It is easy to see that K(0)=μ(ℝn)K(0) = \mu(\mathbb R^n), and thus if we assume K(0)=1K(0) = 1 then the spectral measure is a probability measure.

Random Fourier Features

Picking up where we left: We want to find a low-dimensional mapping of xix_i's into a latent space such that we can approximate the kernel computation with an inner product in this latent space. We will use Bochner's theorem for this. To apply this theorem we need to limit ourselves to a special class of kernels.

Definition 29: A kernel function K:ℝd×ℝd→ℂK : \mathbb R^d \times \mathbb R^d \to \mathbb{C} is called shift-invariant if K(x,y)=K(x−y,0).K(x, y) = K(x-y, 0).

Gaussian and Laplacian kernels are examples of shift-invariant kernels.

Note that the function K′:ℝd→ℂK': \mathbb R^d \to \mathbb{C} defined by K′(x)=K(x,0)K'(x) = K(x, 0) is positive-definite if KK is a shift-invariant kernel. Bochner's theorem then implies the existence of a spectral measure, μ\mu, such that

K(x,y)=K(x−y,0)=K′(x−y)=∫ℝdexp⁡{−iω⊤(x−y)}dμ(ω).\begin{aligned} K(x, y) = K(x-y, 0) = K'(x-y) = \int _{\mathbb R^d} \exp\{-i\omega^\top (x-y)\} \,\mathrm{d}\mu(\omega).\end{aligned}

Let pp denote the Radon-Nikodym derivative of μ\mu with respect to the Lebesgue measure on ℝd\mathbb R^d (or more simply, the density of μ\mu), then we can write the equation above as

K(x,y)=∫ℝdexp⁡{−iω⊤(x−y)}p(ω)dω.\begin{aligned} K(x, y) = \int _{\mathbb R^d} \exp\{-i\omega^\top (x-y)\} p(\omega) \,\mathrm{d}\omega.\end{aligned}

For example, if we take the Gaussian kernel

K(x,y)=exp⁡(−‖x−y‖222σ2),\begin{aligned} K(x,y) = \exp\left(-\frac{\lVert x-y\rVert^2_2}{2 \sigma^2}\right),\end{aligned}

then since K(0,0)=1K(0,0) = 1, pp is a probability density, and can be easily shown to be Gaussian

p∼𝒩(0,1σ2𝐈d).\begin{aligned} p \sim \mathcal{N}\left(0, \frac{1}{\sigma^2} \mathbf{I}_d\right).\end{aligned}

We now see an obvious way to approximate the kernel from equation (1): use Monte Carlo approximation. If we take SS samples, ω1,…,ωS∼p(ω)\omega_1, \ldots, \omega_S \sim p(\omega),

K(x,y)=∫ℝdexp⁡{−iω⊤(x−y)}p(ω)dω≈1S∑s=1Sexp⁡{−iωs⊤(x−y)}=⟨z(x),z(y)⟩,\begin{aligned} K(x, y) &= \int_{\mathbb R^d} \exp\{-i\omega^\top (x-y)\} p(\omega) \,\mathrm{d}\omega \\ &\approx \frac{1}{S} \sum _{s=1}^S \exp\{-i\omega^\top_s (x-y)\} \\ &= \left\langle z(x),z(y) \right\rangle, \end{aligned}

where z:ℝd→ℝSz : \mathbb R^d \to \mathbb R^S is the latent mapping given by

z(x)=1S[exp⁡(−iω1⊤x),…,exp⁡(−iωS⊤x)]⊤.\begin{aligned} z(x) = \frac{1}{\sqrt{S}}[\exp(-i \omega ^\top _1 x), \ldots, \exp(-i \omega ^\top _S x)]^\top.\end{aligned}

We can get another mapping by noting that if the kernel is real, then from (1) we can see that the RHS must also be real and we can thus write it as

K(x,y)=∫ℝdcos⁡{ω⊤(x−y)}p(ω)dω.\begin{aligned} K(x, y) = \int _{\mathbb R^d} \cos\{\omega^\top (x-y)\} p(\omega) \,\mathrm{d}\omega.\end{aligned}

Using the fact that cos⁡(a−b)=cos⁡(a)cos⁡(b)+sin⁡(a)sin⁡(b)\cos(a - b) = \cos(a) \cos(b) + \sin(a) \sin(b), we can write cos⁡{ω⊤(x−y)}=cos⁡(ω⊤x)cos⁡(ω⊤y)+sin⁡(ω⊤x)sin⁡(ω⊤y).\cos\{\omega^\top (x-y)\} = \cos(\omega^\top x) \cos(\omega^\top y) + \sin(\omega^\top x) \sin(\omega^\top y). Thus, if we define z1:ℝd→ℝ2Sz_1 : \mathbb R^d \to \mathbb R^{2S} by

z1(x)=1S[cos⁡(ω1⊤x),…,cos⁡(ωS⊤x),sin⁡(ω1⊤x),…,sin⁡(ωS⊤x)]⊤\begin{aligned} z_1(x) = \frac{1}{\sqrt{S}}[\cos(\omega^\top_1 x), \ldots, \cos(\omega^\top_S x), \sin(\omega^\top_1 x), \ldots, \sin(\omega^\top_S x)]^\top\end{aligned}

we have ⟨z1(x),z1(y)⟩≈K(x,y).\left\langle z_1(x),z_1(y) \right\rangle \approx K(x, y). Another mapping that is used is z2:ℝd→ℝSz_2 : \mathbb R^d \to \mathbb R^{S} defined by

z2(x)=2S[cos⁡(ω1⊤x+b1),…,cos⁡(ωS⊤x+bS)]⊤,\begin{aligned} z_2(x) = \sqrt{\frac{2}{S}}[\cos(\omega^\top_1 x + b_1), \ldots, \cos(\omega^\top_S x + b_S)]^\top,\end{aligned}

where b1,…,bS∼Unif[0,2π].b_1, \ldots, b_S \sim \text{Unif}[0, 2\pi]. It is not too difficult to show that

𝔼[z2(x)⊤z2(y)]=𝔼[z1(x)⊤z1(y)].\begin{aligned} \mathbb{E}[z_2(x)^\top z_2(y)] = \mathbb{E}[z_1(x)^\top z_1(y)].\end{aligned}

There exist many modifications to the basic RFF approach described here. For example, we can do Quasi-Monte Carlo approximations instead of Monte Carlo approximations. See the paper Quasi-Monte Carlo Feature Maps for Shift-Invariant Kernels by Avron, Sindhwani, Yang and Mahoney (2016). Or we could sample from a modified distribution in Fourier space, given by the leverage function of the kernel. See the paper Random Fourier Features for Kernel Ridge Regression: Approximation Bounds and Statistical Guarantees by Avron et al (2017).

Extension to a more general class of kernels

I have often seen kernels being represented as an integral of a product of two functions neatly separating the dependence on xx and yy:

K(x,y)=∫Ωφ(ω,x)φ(ω,y)dμ(ω),\begin{aligned} K(x,y) = \int_{\Omega} \varphi(\omega, x) \varphi(\omega, y) \mathrm{d}\mu(\omega),\end{aligned}

for some function φ(⋅,⋅)\varphi(\cdot, \cdot) and measure μ\mu on Ω.\Omega. I found a good explanation of when this is possible in the papers by Bach (2017) Breaking the Curse of Dimensionality with Convex Neural Networks and Li et al (2019) Towards a Unified Analysis of Random Fourier Features.

Let μ\mu be a Borel probability measure on a compact space Ω\Omega, and φ:Ω×𝒳→ℝ\varphi: \Omega \times \mathcal{X} \to \mathbb R be a function such that the functions φ(⋅,x):Ω→ℝ\varphi(\cdot, x) : \Omega \to \mathbb R are measurable for all x∈𝒳x \in \mathcal{X}. Now define the set ℋ\mathcal{H} to consist of all functions ff that can written as

f(x)=∫Ωh(ω)φ(ω,x)dμ(ω)for all x∈𝒳,\begin{aligned} f(x) = \int_{\Omega} h(\omega) \varphi(\omega, x) \,\mathrm{d}\mu(\omega) \quad \text{for all } x \in \mathcal{X},\end{aligned}

for some h:Ω→ℝh: \Omega \to \mathbb R such that ∫Ωh2dμ<∞.\int_{\Omega} h^2 \,\mathrm{d}\mu < \infty. Let us define the squared norm, ‖f‖ℋ2\lVert f \rVert_{\mathcal{H}}^2, as the infimum of ∫Ωh2dμ\int_{\Omega} h^2 \,\mathrm{d}\mu over all functions hh for which ff can be decomposed as above. Then it can be shown that ℋ\mathcal{H} is an RKHS with the kernel

K(x,y)=∫Ωφ(ω,x)φ(ω,y)dμ(ω).\begin{aligned} K(x,y) = \int_{\Omega} \varphi(\omega, x) \varphi(\omega, y) \,\mathrm{d}\mu(\omega).\end{aligned}

Therefore, we can again approximate this kernel with a Monte Carlo approximation:

K(x,y)=∫Ωφ(ω,x)φ(ω,y)dμ(ω)≈1S∑s=1Sφ(ωs,x)φ(ωs,y).\begin{aligned} K(x,y) &= \int_{\Omega} \varphi(\omega, x) \varphi(\omega, y)\,\mathrm{d}\mu(\omega)\\ &\approx \frac{1}{S} \sum_{s=1}^S \varphi(\omega_s, x) \varphi(\omega_s, y). \end{aligned}

Epilogue

Random Fourier Features is an easy to implement approach that allows us to apply kernel methods on large data sets. I haven't discussed the number of samples, SS, needed to approximate the kernel function within an error bound. You can find such results in the papers linked above.
